# RepairTrace Find Android wrapper

This Android Studio project displays the live RepairTrace Find app at:

https://repairtrace-find.trylegendxd.chatgpt.site

Open this directory in Android Studio and allow Android Studio to synchronize Gradle. Build a debug APK with **Build > Build APK(s)**.

This is source for reproducible rebuilding. It intentionally does not contain a private signing key, Play Store credentials or an unverified prebuilt APK.
